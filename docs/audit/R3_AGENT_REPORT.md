## Conflictos resueltos por el orquestador

1. **C vs H (androidTest Room 8→9)**: verificación directa — `MIGRATION_8_9` existe (AppDatabase.kt:140) y el único androidTest (`HealthSnapshotMigrationTest.kt`) cubre solo 7→8. **Decisión: H tiene razón**; el androidTest 8→9 es pendiente (T-1).
2. **A vs H (conteo tests)**: A cuenta 587 `@Test` estáticos vs 588 ejecutados (Gradle expande/ignora según variantes). No es conflicto real; se registra como D-3 (menor) para uniformar métricas.
3. **B vs proyecto actual**: la app NO tiene WAKE_LOCK declarado — B lo clasifica P0; sin embargo la evidencia de hoy (ZTE con GPS activo 10 h) sugiere que el freeze observado fue de red, no de proceso. **Decisión: añadir wake lock parcial + alarma exacta en F12 con tests de política, como mejora de robustez (no como fix de bug demostrable).**
4. **E vs R0**: el snapshot `backups/*.tar.gz` contiene secretos. **Decisión**: se mantiene como punto de restauración pero restringido a 0600 (hecho), documentado en SECURITY_AUDIT; alternativa cifrada si el operador lo prefiere.
